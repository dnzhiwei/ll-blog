这是你的第一篇博客文章。本站点基于 [Hexo](https://hexo.io/) 静态博客框架，并使用 [Icarus](https://ppoffice.github.io/hexo-theme-icarus/) 主题。

## 快速开始

### 创建新文章

```bash
hexo new "文章标题"
```

### 本地预览

```bash
hexo server
```

浏览器访问 http://localhost:4000 即可预览。

### 生成静态文件

```bash
hexo generate
```

生成的静态文件位于 `public/` 目录，可用于部署到任意静态托管服务。
